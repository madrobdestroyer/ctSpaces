# ctSpaces 6.0.2.0

## Expanded read-only Quick tour

The optional Quick tour now contains 20 steps, including 12 inert workflow
illustrations. It continues to highlight the
real launcher controls and explains existing workflows, including:

- normal pinned-client open/show behavior and the pinned-client menu;
- copied-link handling and both Desktop-shortcut paths;
- pin and session-tab reordering;
- rename, archive/restore, client-first titles, Default save/discard, and
  independent browser-slot choices;
- inactive-client cleanup and manual multi-client deletion.

The additional menu and drag diagrams are explicitly inert illustrations. The
tour never reads the clipboard, launches a browser, creates a client, changes
pins or sessions, runs cleanup/deletion, or changes client/browser preferences.
The launcher controls remain disabled while the tour is open.

## New to colleagues upgrading from 5.2.0.14

What's new now highlights eight relevant guide topics, rather than announcing
only the latest Help update. Related Options commands carry a dot and `(New)`
label. Acknowledging a written-guide page clears its own related markers;
skipping or closing does not silently acknowledge the other features. The
written guide also explains legacy browser-profile handling, simpler text-field
menus, shortcut/taskbar behavior, and cleanup retry safety.

These markers describe the accumulated upgrade from 5.2.0.14. They do not mean
all of these capabilities were first introduced in 6.0.2.0.

This is an expansion of help for existing behavior, not a new client-profile
or browser-data feature. The runtime ZIP remains app-only and contains exactly
`ctSpaces.exe`; documentation and historical validation reports remain in the
repository.

The 6.0.1.0 nine-step tour and its validation record remain available as the
previous-release reference.

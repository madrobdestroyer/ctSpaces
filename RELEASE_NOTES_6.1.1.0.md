# ctSpaces 6.1.1.0

Fixes the Close all hint appearing blank because its text and background
could both be black. The hint now follows the selected theme at startup
and after theme changes. Restore tabs receives the same correction.

This is a focused visual fix. Close All Clients, filtering, notes, browser
profiles, saved sessions, and settings retain their existing behavior.

The application ZIP still contains exactly one file, `ctSpaces.exe`.
Source, tests, and documentation remain in the GitHub repository.

# ctSpaces 6.2 (6.2.1.0)

Client Notes has a redesigned window with an integrated title and close X, slimmer ticket tabs, a grouped icon toolbar, themed dropdowns, and a padded document area. The footer shows autosave status without Save or Cancel buttons.

- Existing notes remain in **Notes**. Use **+** to add a named ticket tab; double-click a tab or right-click it to rename it.
- The editor opens compactly and remembers resizing and maximization. Drag the title area to move it, or double-click the title area to maximize and restore.
- Headings, subheadings, readable default text, yellow highlights, and larger checklist markers improve document formatting. Completed checklist text is struck through, and a checklist action is one undo step.
- Autosave runs after a brief typing pause. Switching tabs or closing with **X** finishes any pending save. Failed saves retain the open draft.
- Web links continue to open in the note's client browser space after confirmation.

The ZIP contains exactly one file: **ctSpaces.exe**. Extract and run it to update. Notes storage, existing client profiles, and legacy notes remain compatible with 6.2.0.0.

The existing Firefox limitation remains: an already-open isolated Firefox client cannot accept another command-line URL. The app reports this instead of starting another writer for that profile.

# ctSpaces 6.2 (6.2.3.0)

This update fixes interaction and rendering problems in Client Notes.

- Resizing and maximizing no longer repaint controls at temporary sizes or leave incomplete chrome behind.
- Removed the unwanted native outer frame; the notes window keeps its subtle themed border and resize handles.
- The highlighter arrow opens a color menu with yellow, green, blue, pink, and no highlight. The marker button uses the last chosen color.
- **+** opens an **Untitled** tab immediately. Start typing, then optionally double-click or right-click the tab to rename it.
- Removed both footer lines and gave their space to the document. Autosave continues; a failure appears in the title and prevents closing an unsaved draft.

Notes continue to use the selected application theme, slim ticket tabs, and remembered window dimensions. Existing note content and formatting remain intact.

The download ZIP contains one `ctSpaces.exe`. Close the old application before replacing its executable. Client data remains in its existing location.

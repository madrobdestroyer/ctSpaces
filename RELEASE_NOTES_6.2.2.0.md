# ctSpaces 6.2 (6.2.2.0)

Client Notes now uses the approved reference's shaded tabs and dropdowns, softer separators, quieter footer, and refined formatting icons. The window and controls share a continuous background, and the link icon has been corrected.

- Large checklist boxes now retain their spacing and appearance after saving, reopening, and changing themes. Earlier saved wide-space tokens are handled when loading.
- All notes surfaces and selection accents continue to follow the chosen application theme.
- Slim ticket tabs, the compact initial window, remembered resizing and maximization, and autosave without footer buttons remain in place.
- Existing note text, font sizes, formatting, ticket names, and client data are preserved. Sample content from the design reference is not inserted into users' notes.

The ZIP contains exactly one file: **ctSpaces.exe**. Extract and run it to update. Notes storage remains compatible with 6.2.0.0 and 6.2.1.0.

The existing limitation for opening another URL in an already-running isolated Firefox client remains unchanged.

# ctSpaces 6.3.3.0

Notes quick actions now share one compact, left-aligned row below the note
heading: Find, Snippets, Templates, Details, Status, Link/Open ticket and Add
update. The smaller buttons use the same themed surfaces as the Notes toolbar,
with hover and keyboard focus feedback. They replace the stacked action buttons
on the right.

Ticket and tag context remains beside the heading, and the editor gains a little
vertical space while keeping its full width. All notes, Trash, More and Help
remain in the top header; Details still opens on demand.

The compact client selector, quiet autosave, slim tabs and same-window client
switching remain intact. This is one patch release for the completed refresh.
The existing application walkthrough videos remain unchanged.

See [release validation](docs/RELEASE_VALIDATION_6.3.3.0.md) for the focused layout,
action, resize and visual checks. Completed broader coverage is preserved in the
[6.3.2.0 validation](docs/RELEASE_VALIDATION_6.3.2.0.md) and
[6.3.1.0 full-app review](docs/FULL_APP_STRESS_REVIEW_6.3.1.0.md).
